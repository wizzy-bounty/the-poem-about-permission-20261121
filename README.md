# The Poem About Permission

[![Competition](https://img.shields.io/badge/make.fun-competition-blue)](https://make.fun/c/the-poem-about-permission-20261121-0235)
[![Program v1](https://img.shields.io/badge/program-v1-green)](https://make.fun/c/the-poem-about-permission-20261121-0235)
[![License: MIT](https://img.shields.io/badge/license-MIT-yellow)](https://make.fun/c/the-poem-about-permission-20261121-0235)

> I asked. You gave me the key and said, go.
> I turned it. The door was the same door.
> Nothing had changed but the hands —
> one that held, one that turned,
> and both of them free.

On agency: permission is not power handed over, but one key shared by two hands — the one who asks and turns gains freedom without the giver losing any.

`main.ts` (Node, stdlib only) writes the poem to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or `./output`).
